Hear it.

Some text is better heard than read. A long changelog, a doc someone dropped in a channel, an email that can wait until you look away. Select it anywhere, press F8, and Omatalk reads it aloud. The voice runs on your own CPU, so nothing leaves the machine. It starts talking about a third of a second after you press the key. Dictation turns your voice into text. This is the other half.

In the default voice, rendered by Omatalk.

install on Omarchy 
omarchy pkg add omatalk-bin && omatalk setup

Setup downloads the voice (about 355 MB), starts the service, asks before it binds F8, and adds the megaphone to your bar.

The other half of voice

Keep both: voxtype dictates on F9, and Omatalk reads back on F8.

F9 You talk. It types. Dictation: voxtype, superwhisper, Hex
F8 You select. It talks. Omatalk: any text in any app, read back in about 0.3 s

Press F8 again to stop, or select something new and press it to switch. With nothing selected, it reads the clipboard. If F8 is already taken, setup leaves it alone and prints the line to add to ~/.config/hypr/bindings.lua with a key of your choice:

~/.config/hypr/bindings.lua 
o.bind("F8", "Omatalk", "omatalk speak")

Hear all 28 voices

Every clip is the same line, rendered on a CPU by the same pipeline Omatalk runs. American and British English. af_heart is the default.

af American femaleam American malebf British femalebm British male

Pick one from the megaphone in the Omarchy bar, or set it in the config file. Every key is optional, and the next press picks up a change. The README lists the rest.

~/.config/omatalk/config.toml 
voice = "af_heart"
speed = 1.0
pause_media = true

Fast because it stays warm. Private because it stays here.

Always warm
A small Rust Daemon loads the model at login, so a press never waits for it. Speech streams batch by batch, starting with the first few words.
On your CPU
Kokoro-82M through ONNX Runtime. No network calls at runtime, no API key, no account, no telemetry.
Made for Omarchy
It reads the Wayland selection, plays through PipeWire, pauses your music while it speaks, and shows its state in the bar.
A real package
omatalk-bin installs with omarchy pkg add and updates with omarchy update, bar plugin included.

The README covers the config, troubleshooting, and design decisions.

Turn a script into a voiceover

omatalk render writes a whole script to a WAV file for a video, a screencast, or a podcast. It favors quality over speed, and a blank line in the script becomes a pause.

from a script file 
omatalk render --out talk.wav < script.txt
one line, a voice, a speed 
omatalk render --out talk.wav --voice af_bella --speed 0.95 "Welcome to the demo."
  • ~10 s per minute of audio (Ryzen 7840HS)
  • WAV 16-bit mono, 24 kHz
  • offline works with the Daemon stopped

Get it on Omarchy

One line installs it, and omarchy update keeps it current.

install on Omarchy 
omarchy pkg add omatalk-bin && omatalk setup

Setup downloads the voice (about 355 MB), starts the service, asks before it binds F8, and adds the megaphone to your bar.

Remove it, or move from the old installer

Run the line below to remove it. It asks before it deletes the voice models, your config, and the F8 binding. Installed Omatalk before it was a package? Run omatalk upgrade once instead.

uninstall 
omatalk uninstall
